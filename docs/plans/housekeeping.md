# housekeeping Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a fourth plugin, `housekeeping`: one plugin with one version and three read-only skills, built one release at a time. **doc-truth** (0.1.0) checks that what a repository's markdown documents say exists; **handoff** (0.2.0) writes an end-of-session note whose git facts come from git and whose citations are verified, and checks them again when the note is resumed; **todo-sweep** (0.3.0) triages `TODO` and `FIXME` comments, oldest first, as cards on the ar-board panel and records the decision in a read-only report.

**Architecture:** Three standalone Python scripts (`doc_truth.py`, `handoff.py`, `todo_sweep.py`), each run with `python3 -I`, so the few helpers they share (a git wrapper, a fingerprint, a config loader) are duplicated on purpose, as publish-check and tidy-board already do. They carry the plugin's version in `VERSION` and `tools/sync.py` keeps the manifest, the changelog and the headers consistent. Only todo-sweep needs the panel: it ships `capy_board.py`, a generated byte copy of the ar-board engine (no engine change in this plan). doc-truth is dogfooded: a test runs it on this repository and expects no findings.

**Tech Stack:** Python 3.9+ standard library and `git`; `unittest` with throwaway git repositories. No JavaScript is added.

**Spec:** [docs/refinements/housekeeping.md](../refinements/housekeeping.md) (decisions H01-H14, rulings R1-R19, amendments). Conventions this plan follows: [CLAUDE.md](../../CLAUDE.md).

## Global Constraints

- Python standard library only; Python 3.9 compatible (no `match`, no `X | Y` runtime types, no `str.removeprefix`); `git` is required. The plan was verified on the machine's default Python (3.15) and on the system Python 3.9.6.
- No network, anywhere. No tool runs a command a document cites. No tool edits a tracked source file: doc-truth never writes; handoff writes only its notes (private files, never over another, and it refuses a `.handoff` folder that is a symlink); todo-sweep writes only inside `.todo-sweep/` (batches, reports, the ledger; it refuses a symlinked folder).
- Hostile repository content is data: tracked symlinks are never followed (documents, manifests, sources, notes), a note's data block is used only when it has exactly the shape `collect` writes, and the git config of the repository is still trusted (the docs say not to run the tools on a repository you do not trust).
- One plugin version for all scripts: each script's header comment (`# <name> X.Y.Z - ...`) and `VERSION = "X.Y.Z"` equal the plugin version, and `tools/sync.py --check` fails otherwise. The bumps are Tasks 5 (0.2.0) and 7 (0.3.0); the changelog entry of a release is written when its first task starts.
- Tool output is accent-free Portuguese (the repository convention for UI strings); `SKILL.md` files are Portuguese; documentation is English with `.pt-BR.md` counterparts that keep the same heading levels (doc-truth checks it).
- Never edit generated files by hand: `plugins/housekeeping/.claude-plugin/plugin.json` and `.claude-plugin/marketplace.json` follow the scripts' version (`python3 plugins/housekeeping/tools/sync.py`, then `python3 tools/marketplace.py`), and `plugins/housekeeping/skills/todo-sweep/scripts/capy_board.py` is a byte copy of the ar-board engine (after editing or releasing `ar_board.py`, run the ar-board sync, then this one).
- doc-truth judges the **git tree**, so `git add -A` before running the suite or the tool, or a new document looks like a missing file.
- Test fixtures build throwaway repositories under a temporary directory with a fixed fake identity (`alice@example.com`, which publish-check ignores) and `GIT_CONFIG_GLOBAL` pointed at the null device; no real address or home path may appear in the tree. `tests/helpers.py` sets `sys.dont_write_bytecode`; run tests with `PYTHONDONTWRITEBYTECODE=1`.
- Every commit is authored with the owner's personal address, pinned in the repo-local git config; never use the work address. Wherever this plan writes `OWNER_EMAIL`, write the address printed by `git config --local user.email`. No commit trailer may contain a claude.ai session link (publish-check flags it): end commit messages with the single line `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Git flow of this machine: the branch is cut from the one that holds the spec and this plan, merged locally into `base` when done, **no push and no PR unless the owner asks**.

## Review Focus

Failure modes the spec implies but a first pass would not test; each line has a test in the task that owns the code.

1. **A hostile repository:** a tracked `.md` that is a symlink to a file outside, a symlinked manifest, a `.handoff` or `.todo-sweep` that is a symlink, a planted note whose data block has the wrong shape or a base that is not a ref, a TODO file that is a symlink (Tasks 1, 3, 5-8).
2. **False alarms that would make doc-truth useless:** tree diagrams, placeholders (`<name>`, `PATH`), URLs, MIME types, `A/R/M`, bare extensions, run-time file names, shorthand paths, `file.py:42` (Tasks 2 and 4); and the first run on this repository, which must end at zero findings with real drift fixed (Task 4).
3. **Citation traps:** `added` and `deadbeef` are not commit ids, a tag is not a branch even when named like a missing one, option-looking names, absolute and `..` paths, a symlink leaving the repository, a file the session deleted (Task 5).
4. **Idempotence:** the ` [nao verificado]` mark is added once and nothing is removed, two notes in one second never share a file, the report can be run twice, a note with a commit subject containing `-->` round-trips (Tasks 5, 6, 8).
5. **Writing a note must not change what it records:** `.handoff/` is left out of the git facts, otherwise `resume` would always report drift (Tasks 5 and 6).
6. **Age:** a repository's root commit is a blame boundary but has a real age; only a shallow clone's boundary has none; uncommitted lines, a staged new file, a failing blame and the cap each say why they have no age (Task 7).
7. **Rounds and refusals:** the ledger makes the next scan offer the next TODOs; an unfinished board, another round or batch, garbage, a hand-edited sidecar, a vanished repository and a corrupt ledger are all refused **before anything is written** (Tasks 7 and 8).

import sys

sys.dont_write_bytecode = True  # never leave __pycache__ inside the plugin (it would ship with it)

import importlib.util
import os
import subprocess
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent  # the plugin directory (plugins/housekeeping)
REPO = ROOT.parent.parent  # the marketplace repository root
SKILLS = ROOT / "skills"
DOC_TRUTH = SKILLS / "doc-truth" / "scripts" / "doc_truth.py"
HANDOFF = SKILLS / "handoff" / "scripts" / "handoff.py"
TODO_SWEEP = SKILLS / "todo-sweep" / "scripts" / "todo_sweep.py"
CAPY = SKILLS / "todo-sweep" / "scripts" / "capy_board.py"
ENGINE = REPO / "plugins" / "ar-board" / "skills" / "ar-board" / "scripts" / "ar_board.py"


def load_module(path, name):
    spec = importlib.util.spec_from_file_location(name, path)
    mod = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(mod)
    return mod


def load_doc_truth():
    return load_module(DOC_TRUTH, "doc_truth")


def load_handoff():
    return load_module(HANDOFF, "handoff")


def load_todo_sweep():
    return load_module(TODO_SWEEP, "todo_sweep")


def load_capy():
    """The vendored engine, to validate the batches the tool writes with the real `check`."""
    return load_module(CAPY, "capy_board")


def load_engine():
    """The ar-board engine itself, to validate the batches the tools write with its real `validate`."""
    return load_module(ENGINE, "ar_board_engine")


def load_sync():
    return load_module(ROOT / "tools" / "sync.py", "housekeeping_sync")


def _env(date=None):
    env = {k: v for k, v in os.environ.items() if not k.startswith("GIT_")}
    env.update(
        GIT_CONFIG_GLOBAL=os.devnull,
        GIT_CONFIG_NOSYSTEM="1",
        GIT_AUTHOR_NAME="Alice Example",
        GIT_AUTHOR_EMAIL="alice@example.com",
        GIT_COMMITTER_NAME="Alice Example",
        GIT_COMMITTER_EMAIL="alice@example.com",
    )
    if date:
        env.update(GIT_AUTHOR_DATE=date, GIT_COMMITTER_DATE=date)
    return env


def git(repo, *args, date=None, input=None, check=True):
    r = subprocess.run(["git", "-C", str(repo), "-c", "commit.gpgsign=false", "-c", "tag.gpgsign=false", *args],
                       env=_env(date), capture_output=True, text=True, input=input)
    if check and r.returncode != 0:
        raise AssertionError(f"git {' '.join(args)} failed: {r.stderr}")
    return r.stdout


def init_repo(path, branch="main"):
    Path(path).mkdir(parents=True, exist_ok=True)
    git(path, "init", "-q", "-b", branch)
    return Path(path)


def commit(repo, message, files=None, date=None):
    """Commit `files` ({relative path: text}) and return the new commit id."""
    for rel, text in (files or {}).items():
        target = Path(repo) / rel
        target.parent.mkdir(parents=True, exist_ok=True)
        target.write_text(text, encoding="utf-8")
        git(repo, "add", "--", rel)
    git(repo, "commit", "-q", "--allow-empty", "-m", message, date=date)
    return git(repo, "rev-parse", "HEAD").strip()

```python
#!/usr/bin/env python3
# doc-truth 0.1.0 - confere se o que os documentos dizem existe: caminhos, links, ancoras, paridade EN/PT-BR e versoes (somente stdlib e git)
# SPDX-License-Identifier: MIT
# Copyright (c) 2026 Diogo Winck
#
# Uso:
#   doc_truth.py [PATH] [--json] [--config FILE]     # somente leitura; saida 0 limpo, 1 achados, 2 erro
import argparse
import hashlib
import json
import os
import posixpath
import re
import subprocess
import sys
from pathlib import Path
from urllib.parse import unquote

VERSION = "0.1.0"
SCHEMA = 1  # of the --json output; it is a public contract
CONFIG_NAME = ".doc-truth.json"
CONFIG_KEYS = ("exclude", "ignore_paths", "allow")

# git never prompts, never runs the repository's hooks or a filesystem monitor, and never uses the network
GIT_FLAGS = ["-c", "core.quotepath=off", "-c", "core.fsmonitor=false", "-c", "core.hooksPath=" + os.devnull,
             "-c", "protocol.allow=never"]


class DocTruthError(Exception):
    """Something the person must fix before the check can run (exit code 2)."""


def git(root, *args):
    env = dict(os.environ, GIT_TERMINAL_PROMPT="0")
    return subprocess.run(["git", *GIT_FLAGS, "-C", str(root), *args], capture_output=True, env=env)


def repo_root(path):
    r = git(path, "rev-parse", "--show-toplevel")
    if r.returncode != 0:
        raise DocTruthError(f"{path} nao e um repositorio git")
    return Path(r.stdout.decode("utf-8", "replace").strip())


def tracked_files(root):
    """Every path git tracks, POSIX style: existence is judged against this, so a local run and CI agree."""
    r = git(root, "ls-files", "-z")
    if r.returncode != 0:
        raise DocTruthError(f"{root} nao e um repositorio git")
    return sorted(p for p in r.stdout.decode("utf-8", "replace").split("\0") if p)


def tree_paths(files):
    """The tracked files plus every folder they imply."""
    out = set(files)
    for f in files:
        d = posixpath.dirname(f)
        while d:
            out.add(d)
            d = posixpath.dirname(d)
    return out


def read_text(root, rel):
    """A tracked file's text, or None. Symlinks are never followed (a hostile repository could point one outside
    itself) and anything that is not a regular file is skipped."""
    path = Path(root) / rel
    try:
        if path.is_symlink() or not path.is_file():
            return None
        return path.read_text(encoding="utf-8", errors="replace")
    except OSError:
        return None


def load_config(root, explicit=None):
    path = Path(explicit) if explicit else Path(root) / CONFIG_NAME
    cfg = {k: [] for k in CONFIG_KEYS}
    if not path.exists():
        if explicit:
            raise DocTruthError(f"{path}: arquivo de configuracao nao encontrado")
        return cfg
    try:
        data = json.loads(path.read_text(encoding="utf-8"))
    except (OSError, ValueError) as e:
        raise DocTruthError(f"{path}: {e}")
    if not isinstance(data, dict):
        raise DocTruthError(f"{path}: deve ser um objeto JSON")
    for key, value in data.items():
        if key not in CONFIG_KEYS:
            raise DocTruthError(f"{path}: chave desconhecida '{key}' (use {', '.join(CONFIG_KEYS)})")
        if not isinstance(value, list) or not all(isinstance(x, str) for x in value):
            raise DocTruthError(f"{path}: '{key}' deve ser uma lista de textos")
        cfg[key] = value
    return cfg


def glob_regex(pattern):
    """`*` is a name part (never crosses `/`), `**` is any depth. A pattern with no `/` except a trailing one
    matches a name anywhere (like .gitignore); a pattern with a `/` inside is anchored at the repository root;
    a trailing `/` means the folder itself and everything under it."""
    pat = pattern.strip()
    folder = pat.endswith("/")
    if folder:
        pat = pat[:-1]
    anchored = "/" in pat
    out, i = "", 0
    while i < len(pat):
        if pat.startswith("**/", i):
            out += "(?:.*/)?"
            i += 3
        elif pat.startswith("**", i):
            out += ".*"
            i += 2
        elif pat[i] == "*":
            out += "[^/]*"
            i += 1
        elif pat[i] == "?":
            out += "[^/]"
            i += 1
        else:
            out += re.escape(pat[i])
            i += 1
    if folder:
        out += "(?:/.*)?"
    if not anchored:
        out = "(?:.*/)?" + out
    return re.compile("^" + out + "$")


def compile_globs(patterns):
    return [glob_regex(p) for p in patterns]


def matches_any(regexes, rel):
    return any(rx.match(rel) for rx in regexes)

Create `plugins/housekeeping/tools/sync.py`:

```python
#!/usr/bin/env python3
"""Keeps the housekeeping plugin consistent from one source of truth: the VERSION of its scripts.

The plugin has one version and every script (doc_truth.py, handoff.py, todo_sweep.py) carries it as `VERSION`;
a release bumps them together. This tool propagates that version into .claude-plugin/plugin.json and reports
what it cannot fix by itself (scripts that disagree, a stale header comment, a missing CHANGELOG entry).

Usage (from the plugin directory or anywhere):
  python3 tools/sync.py           # write whatever is out of sync
  python3 tools/sync.py --check   # only verify (exit 1 if anything differs or is wrong)
"""
import json
import re
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
SCRIPTS = {  # skill name -> script; only the ones that exist are part of the plugin yet
    "doc-truth": "skills/doc-truth/scripts/doc_truth.py",
    "handoff": "skills/handoff/scripts/handoff.py",
    "todo-sweep": "skills/todo-sweep/scripts/todo_sweep.py",
}
PLUGIN = ".claude-plugin/plugin.json"
CHANGELOG = "CHANGELOG.md"


def read(root, rel):
    return (root / rel).read_text(encoding="utf-8")


def dump_json(obj):
    return json.dumps(obj, indent=2, ensure_ascii=False) + "\n"


def script_version(script):
    return re.search(r'^VERSION = "(\d+\.\d+\.\d+)"', script, re.M).group(1)


def present(root):
    return {name: rel for name, rel in SCRIPTS.items() if (root / rel).exists()}


def versions(root):
    return {name: script_version(read(root, rel)) for name, rel in present(root).items()}


def plugin_version(root):
    return max(versions(root).values(), key=lambda v: tuple(int(n) for n in v.split(".")))


def inputs(root):
    return list(present(root).values()) + [PLUGIN, CHANGELOG]


def build(root):
    """Return {relative path: expected content} for every generated file."""
    plugin = json.loads(read(root, PLUGIN))
    plugin["version"] = plugin_version(root)
    return {PLUGIN: dump_json(plugin)}


def problems(root):
    """Things the tool cannot fix by itself; each one is a message."""
    out = []
    found = versions(root)
    if len(set(found.values())) > 1:
        out.append("the scripts disagree on VERSION: " + ", ".join(f"{n} {v}" for n, v in sorted(found.items())))
    version = plugin_version(root)
    for name, rel in present(root).items():
        if not re.search(rf"^# {re.escape(name)} {re.escape(version)} - ", read(root, rel), re.M):
            out.append(f"{rel}: header comment must say '{name} {version}' (the plugin version is {version})")
    if not re.search(rf"^## \[{re.escape(version)}\]", read(root, CHANGELOG), re.M):
        out.append(f"{CHANGELOG}: no '## [{version}]' entry")
    return out


def main(argv, root=ROOT):
    files = build(root)
    found = problems(root)
    stale = [rel for rel, text in files.items() if not (root / rel).exists() or read(root, rel) != text]
    if "--check" in argv:
        for rel in stale:
            print(f"out of sync: {rel}")
        for msg in found:
            print(f"problem: {msg}")
        return 1 if (stale or found) else 0
    for rel in stale:
        (root / rel).parent.mkdir(parents=True, exist_ok=True)
        (root / rel).write_text(files[rel], encoding="utf-8")
        print(f"updated: {rel}")
    for msg in found:
        print(f"problem: {msg}")
    return 1 if found else 0


if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))
```

FENCE = re.compile(r"^ {0,3}(`{3,}|~{3,})")
HEADING = re.compile(r"^ {0,3}(#{1,6})[ \t]+(.+?)[ \t]*#*[ \t]*$")
SPAN = re.compile(r"(`+)([^`\n]+?)\1")
LINK = re.compile(r"!?\[[^\]\n]*\]\(\s*(<[^>\n]*>|[^)\s]+)(?:\s+(?:\"[^\"]*\"|'[^']*'))?\s*\)")
REFDEF = re.compile(r"^ {0,3}\[[^\]\n]+\]:\s*(<[^>\n]*>|\S+)")
HTML_REF = re.compile(r"""\b(?:href|src)=["']([^"']+)["']""")
TREE_CHARS = "├└│─┌┐┘┬┴┼"
EXTENSIONS = (".md", ".py", ".json", ".sh", ".yml", ".yaml", ".toml", ".html", ".svg", ".txt")
SKIP_CHARS = "<>*$~|@{}"
SCHEME = re.compile(r"^[A-Za-z][A-Za-z0-9+.-]*:")
MIME = re.compile(r"(?:application|text|image|audio|video|font|multipart|message)/[\w.+-]+")


class Doc:
    """What the checks need from one markdown file: headings, backtick spans, fenced lines and link targets.
    Front matter, fenced lines and tree diagrams never count as headings or prose."""

    def __init__(self, text):
        self.headings = []  # (level, text, line)
        self.spans = []  # (line, text) - inline code
        self.fenced = []  # (line, text) - lines inside a code fence
        self.links = []  # (line, target)
        self.prose = []  # (line, text) - everything outside front matter and fences
        lines = text.splitlines()
        start = 0
        if lines and lines[0].strip() == "---":
            for i in range(1, len(lines)):
                if lines[i].strip() == "---":
                    start = i + 1
                    break
        fence = None
        for n in range(start, len(lines)):
            line = lines[n]
            m = FENCE.match(line)
            if fence:
                if m and m.group(1)[0] == fence[0] and len(m.group(1)) >= len(fence) and not line.strip(" `~"):
                    fence = None
                else:
                    self.fenced.append((n + 1, line))
                continue
            if m:
                fence = m.group(1)
                continue
            self.prose.append((n + 1, line))
            h = HEADING.match(line)
            if h:
                self.headings.append((len(h.group(1)), h.group(2), n + 1))
            ref = REFDEF.match(line)
            if ref:
                self.links.append((n + 1, ref.group(1).strip("<>")))
            for s in SPAN.finditer(line):
                self.spans.append((n + 1, s.group(2).strip()))
            bare = SPAN.sub(" ", line)
            for lm in LINK.finditer(bare):
                self.links.append((n + 1, lm.group(1).strip("<>")))
            for hm in HTML_REF.finditer(bare):
                self.links.append((n + 1, hm.group(1)))


def slugify(heading):
    """GitHub's anchor for a heading: lower case, punctuation dropped except - and _, spaces to -, letters kept."""
    text = re.sub(r"!?\[([^\]]*)\]\([^)]*\)", r"\1", heading)
    text = text.replace("`", "").replace("*", "").strip().lower()
    kept = "".join(c for c in text if c.isalnum() or c in " -_")
    return kept.replace(" ", "-")


def anchors_of(doc):
    """Every anchor a document offers; a repeated heading gets -1, -2 ..."""
    seen, out = {}, set()
    for _level, text, _line in doc.headings:
        slug = slugify(text)
        n = seen.get(slug, 0)
        out.add(slug if n == 0 else f"{slug}-{n}")
        seen[slug] = n + 1
    return out


def trim(tok):
    """Punctuation around a token, including a sentence's final full stop."""
    while True:
        new = tok.strip("\"'()[]{},;:!?")
        if new.endswith(".") and not new.endswith(".."):
            new = new[:-1]
        if new == tok:
            return tok
        tok = new


def clean_token(tok):
    tok = trim(tok)
    if re.match(r"^[A-Za-z_][A-Za-z0-9_]*=", tok):  # NAME=value: the value is what may be a path
        tok = trim(tok.split("=", 1)[1])
    return re.sub(r":\d+(?::\d+)?$", "", tok)  # file.py:42


def is_path(tok):
    """Does this token claim to be a repository path? Placeholders, URLs, flags and absolute paths do not."""
    if not tok or tok.startswith("-") or tok.startswith("/") or "..." in tok:
        return False
    if SCHEME.match(tok) or "://" in tok or any(c in tok for c in SKIP_CHARS):
        return False
    if re.fullmatch(r"[A-Z][A-Z0-9_]*", tok):  # PATH, DIR
        return False
    if MIME.fullmatch(tok) or re.fullmatch(r"\.[A-Za-z0-9]+", tok):  # text/html, a bare extension like .svg
        return False
    if all(len(part) == 1 for part in tok.split("/") if part):  # A/R/M, n/N, a/b: choices, not paths
        return False
    return "/" in tok or tok.endswith(EXTENSIONS)


def tokens_of_span(text):
    return [clean_token(t) for t in text.split()]


def tokens_of_fenced_line(text):
    """Shell-ish lines: a leading # is a comment, a leading / is a Claude Code command, a tree diagram is a picture,
    and anything after ` #` is a comment."""
    stripped = text.strip()
    if not stripped or stripped.startswith("#") or stripped.startswith("/") or any(c in text for c in TREE_CHARS):
        return []
    cut = re.split(r"\s#", text, maxsplit=1)[0]
    return [clean_token(t) for t in cut.split()]

```python
def finding(category, document, line, value, message):
    return {"category": category, "document": document, "line": line, "value": value, "message": message}


class Context:
    """The repository as the checks see it: the git tree, the documents (parsed once) and what to ignore."""

    def __init__(self, root, files, config):
        self.root = Path(root)
        self.files = files
        self.tree = tree_paths(files)
        self.ignore = compile_globs(config["ignore_paths"])
        self._docs = {}

    def doc(self, rel):
        if rel not in self._docs:
            text = read_text(self.root, rel)
            self._docs[rel] = Doc(text) if text is not None else None
        return self._docs[rel]


def candidates(document, token):
    """Where a token may point: next to the document first, then from the repository root."""
    t = token.rstrip("/")
    out = []
    for base in (posixpath.dirname(document), ""):
        cand = posixpath.normpath(posixpath.join(base, t))
        if cand != "." and not cand.startswith(".."):
            out.append(cand)
    return out


def path_exists(ctx, document, token):
    return any(c in ctx.tree for c in candidates(document, token))


def is_ignored(ctx, document, token):
    shown = token.rstrip("/")
    forms = [shown[2:] if shown.startswith("./") else shown] + candidates(document, token)
    return any(matches_any(ctx.ignore, f) for f in forms)


def check_paths(ctx, document):
    doc = ctx.doc(document)
    out, seen = [], set()
    pairs = [(n, t) for n, text in doc.spans for t in tokens_of_span(text)]
    pairs += [(n, t) for n, text in doc.fenced for t in tokens_of_fenced_line(text)]
    for line, tok in pairs:
        if tok in seen or not is_path(tok):
            continue
        seen.add(tok)
        if is_ignored(ctx, document, tok) or path_exists(ctx, document, tok):
            continue
        out.append(finding("path", document, line, tok, f"o caminho citado nao existe: {tok}"))
    return out


def check_links(ctx, document):
    doc = ctx.doc(document)
    out, seen = [], set()
    for line, raw in doc.links:
        if raw in seen or SCHEME.match(raw):
            continue
        seen.add(raw)
        target, _, fragment = raw.partition("#")
        target = unquote(target.partition("?")[0])
        fragment = unquote(fragment)
        if target:
            if target.startswith("/"):
                cand = posixpath.normpath(target.lstrip("/"))
            else:
                cand = posixpath.normpath(posixpath.join(posixpath.dirname(document), target))
            if cand.startswith("..") or cand not in ctx.tree:
                out.append(finding("link", document, line, target, f"o link aponta para algo que nao existe: {target}"))
                continue
        else:
            cand = document
        if fragment and cand.endswith(".md") and cand in ctx.files:
            other = ctx.doc(cand)
            if other is not None and fragment.lower() not in anchors_of(other):
                value = f"{cand}#{fragment}"
                out.append(finding("anchor", document, line, value, f"nao ha titulo para a ancora: {value}"))
    return out

MANIFEST = re.compile(r"plugins/[^/]+/\.claude-plugin/plugin\.json")
CATALOG = ".claude-plugin/marketplace.json"
VERSION_IN_TEXT = re.compile(r"(?<![\d.])v?(\d+\.\d+\.\d+)(?!\.?\d)")
VERSION_DOCS = (re.compile(r"README(?:\.pt-BR)?\.md"), re.compile(r"plugins/[^/]+/README(?:\.pt-BR)?\.md"),
                re.compile(r"plugins/[^/]+/skills/[^/]+/SKILL\.md"))
ROOT_READMES = ("README.md", "README.pt-BR.md")


def read_json(ctx, rel):
    text = read_text(ctx.root, rel)
    try:
        data = json.loads(text) if text is not None else None
    except ValueError:
        return None
    return data if isinstance(data, dict) else None


def plugin_versions(ctx):
    """{plugin name: version} from every tracked plugin.json."""
    out = {}
    for rel in ctx.files:
        if MANIFEST.fullmatch(rel):
            data = read_json(ctx, rel)
            if data and isinstance(data.get("name"), str) and isinstance(data.get("version"), str):
                out[data["name"]] = data["version"]
    return out


def check_parity(ctx, documents):
    """X.md and X.pt-BR.md must have the same sequence of heading levels (the text is translated, so it is not
    compared). A README.md with no README.pt-BR.md next to it is a finding; any other document without a pair is not."""
    present = set(documents)
    out = []
    for rel in sorted(present):
        if rel.endswith(".pt-BR.md"):
            continue
        pt = rel[:-3] + ".pt-BR.md"
        if pt not in ctx.files:
            if posixpath.basename(rel) == "README.md":
                out.append(finding("parity", rel, 1, "falta " + posixpath.basename(pt),
                                   f"{rel} nao tem a versao em portugues ({posixpath.basename(pt)})"))
            continue
        if pt not in present:
            continue
        en, br = ctx.doc(rel), ctx.doc(pt)
        a, b = [h[0] for h in en.headings], [h[0] for h in br.headings]
        if a == b:
            continue
        i = next((k for k in range(min(len(a), len(b))) if a[k] != b[k]), min(len(a), len(b)))
        where = f"o titulo {i + 1} difere" if i < min(len(a), len(b)) else f"{len(a)} titulos contra {len(b)}"
        out.append(finding("parity", rel, 1, ",".join(map(str, a)) + "|" + ",".join(map(str, b)),
                           f"os niveis de titulo de {rel} e {pt} diferem ({where})"))
    return out


def check_versions(ctx, documents):
    """A version X.Y.Z written on the same line as a plugin's name must be that plugin's version (or the version of
    another plugin named on the line). Only the root README, plugin READMEs and SKILL.md are checked."""
    versions = plugin_versions(ctx)
    out = []
    for rel in documents:
        if not any(rx.fullmatch(rel) for rx in VERSION_DOCS):
            continue
        for line, text in ctx.doc(rel).prose:
            named = [n for n in versions if re.search(rf"(?<![\w-]){re.escape(n)}(?![\w-])", text)]
            if not named:
                continue
            allowed = {versions[n] for n in named}
            for v in VERSION_IN_TEXT.findall(text):
                if v not in allowed:
                    value = "/".join(named) + " " + v
                    expected = ", ".join(f"{n} {versions[n]}" for n in named)
                    out.append(finding("version", rel, line, value, f"a versao {v} nao bate com o manifesto ({expected})"))
    return out


def check_plugin_lists(ctx, documents):
    """Every plugin of the catalog must be linked from the root README and its Portuguese counterpart."""
    catalog = read_json(ctx, CATALOG) if CATALOG in ctx.files else None
    names = [p["name"] for p in (catalog or {}).get("plugins", []) if isinstance(p, dict) and isinstance(p.get("name"), str)]
    out = []
    for rel in ROOT_READMES:
        if rel not in documents:
            continue
        targets = [posixpath.normpath(t.partition("#")[0]) for _, t in ctx.doc(rel).links if t.partition("#")[0]]
        for name in names:
            if not any(t == f"plugins/{name}" or t.startswith(f"plugins/{name}/") for t in targets):
                out.append(finding("plugins", rel, 1, name, f"o catalogo tem o plugin {name}, mas {rel} nao tem link para plugins/{name}"))
    return out

```python
CATEGORIES = ("path", "link", "anchor", "parity", "version", "plugins")


def fingerprint(f):
    """Category, document and value; never the line, so an edit above an accepted finding does not revive it."""
    return hashlib.sha256(f"{f['category']}|{f['document']}|{f['value']}".encode("utf-8")).hexdigest()[:16]


def run(root, config):
    files = tracked_files(root)
    ctx = Context(root, files, config)
    exclude = compile_globs(config["exclude"])
    documents = [f for f in files if f.endswith(".md") and not matches_any(exclude, f) and ctx.doc(f) is not None]
    found = []
    for doc in documents:
        found += check_paths(ctx, doc) + check_links(ctx, doc)
    found += check_parity(ctx, documents) + check_versions(ctx, documents) + check_plugin_lists(ctx, documents)
    for f in found:
        f["fingerprint"] = fingerprint(f)
    allow = set(config["allow"])
    kept = [f for f in found if f["fingerprint"] not in allow]
    kept.sort(key=lambda f: (CATEGORIES.index(f["category"]), f["document"], f["line"], f["value"]))
    return {"schema": SCHEMA, "tool": "doc-truth", "version": VERSION, "root": str(root), "documents": len(documents),
            "findings": kept, "accepted": len(found) - len(kept)}


def report(result):
    lines = [f"doc-truth {result['version']}: {result['documents']} documentos conferidos em {result['root']}"]
    kept = result["findings"]
    lines.append(f"{len(kept)} achados" if kept else "limpo: nenhum achado")
    for cat in CATEGORIES:
        group = [f for f in kept if f["category"] == cat]
        if not group:
            continue
        lines += ["", f"[{cat}] {len(group)}"]
        for f in group:
            lines += [f"  {f['document']}:{f['line']}  {f['value']}", f"    {f['message']}", f"    fingerprint: {f['fingerprint']}"]
    if result["accepted"]:
        lines.append(f"({result['accepted']} aceitos pela lista allow)")
    if kept:
        lines += ["", f'Para aceitar um achado, ponha o fingerprint em "allow" em {CONFIG_NAME}.']
    return "\n".join(lines)


def parser():
    p = argparse.ArgumentParser(prog="doc_truth.py", description="Confere se o que os documentos de um repositorio dizem existe (somente leitura).")
    p.add_argument("path", nargs="?", default=".", help="o repositorio (padrao: a pasta atual)")
    p.add_argument("--json", action="store_true", help="saida em JSON (campo schema)")
    p.add_argument("--config", help=f"arquivo de configuracao (padrao: {CONFIG_NAME} na raiz do repositorio)")
    p.add_argument("--version", action="version", version=f"doc-truth {VERSION}")
    return p


def main(argv=None):
    args = parser().parse_args(argv)
    try:
        root = repo_root(args.path)
        config = load_config(root, args.config)
        result = run(root, config)
    except DocTruthError as e:
        print(f"erro: {e}", file=sys.stderr)
        return 2
    print(json.dumps(result, indent=2, ensure_ascii=False) if args.json else report(result))
    return 1 if result["findings"] else 0


if __name__ == "__main__":
    sys.exit(main())

# doc-truth (os documentos dizem a verdade?)

Lê todo `.md` rastreado pelo git e confere o que ele afirma contra o repositório: o caminho citado existe, o link e a âncora levam a algum lugar, o `README.md` e o `README.pt-BR.md` têm a mesma estrutura, a versão escrita ao lado do nome de um plugin é a do manifesto. É **somente leitura**: nunca altera o repositório, nunca roda um comando citado e não usa a rede. Requer `python3` (stdlib) e `git`.

Não confere links externos (`https://...`) nem se uma descrição está certa, só se o que ela aponta existe.

## Quando usar

Quando o usuário pedir para conferir a documentação: depois de editar READMEs ou `docs/`, antes de um lançamento, ou numa dúvida ("o README ainda cita esse arquivo?"). Não se ofereça sozinho: é uma ferramenta de pedido explícito.

## Fluxo

### 0. Localizar o script

O script acompanha esta skill: `${CLAUDE_SKILL_DIR}/scripts/doc_truth.py`. Use-o direto, sempre com `python3 -I`.

- `link` e `anchor`: o link aponta para algo que não existe, ou não há título para a âncora (regras de slug do GitHub);
- `parity`: `<name>.md` e `<name>.pt-BR.md` têm sequências de níveis de título diferentes, ou um `README.md` não tem o `README.pt-BR.md`;

Corrigir o texto de um documento é uma edição comum, que você só faz quando o usuário pedir, mostrando o que muda. **Não edite `.doc-truth.json`** (nem `allow`, nem `exclude`) sem o OK do usuário: aceitar um achado é decisão dele. Para aceitar, o usuário põe o `fingerprint` do achado em `allow`; ele não depende do número da linha.

## Configuração (`.doc-truth.json`)

```json
{
  "exclude": ["docs/plans/**", "**/CHANGELOG.md"],
  "ignore_paths": [".ar-board/", "decisions.json"],
  "allow": []
}
```

- `exclude`: documentos que não são conferidos (históricos, gerados). Eles continuam valendo como alvo de link.
- `ignore_paths`: caminhos que não existem na árvore de propósito (criados em execução). Um padrão sem `/` vale para o nome em qualquer pasta; com `/` no meio, parte da raiz; `**` atravessa pastas e `*` não.
- `allow`: fingerprints de achados aceitos.
- Chave desconhecida é erro (saída 2).

## Regras

- Somente leitura, sem rede. Nunca rode um comando que um documento cita.
- Diagramas de árvore (linhas com `├──`) não são conferidos: são desenhos.
- Não rode em um repositório em que você não confia: o git lê a configuração local dele. Se `git` não existir no PATH, diga isso ao usuário em vez de tentar outra forma.

- **Languages:** the skills are in Portuguese; the documentation is in English ([README.pt-BR.md](README.pt-BR.md) is the Portuguese counterpart).

## Skills

### doc-truth

Reads every git-tracked `.md` file and checks what it claims against the repository. Ask Claude *"check the docs"* or call `/housekeeping:doc-truth`, or run it yourself:

```bash
S=plugins/housekeeping/skills/doc-truth/scripts
python3 -I $S/doc_truth.py            # this repository
python3 -I $S/doc_truth.py --json     # machine-readable, with a schema field
```

Exit code `0` clean, `1` findings, `2` error (not a git repository, bad config). It never writes, never runs a command a document cites and never uses the network.

| Category | What it checks |
| --- | --- |
| `path` | A path cited in backticks or in a code block exists in the **git tree** (not only on your disk, so a local run and CI agree). Placeholders (`<name>`, `PATH`), URLs, flags, absolute paths, tree diagrams and choices such as `A/R/M` are not paths. |
| `link`, `anchor` | A relative link points to something that exists, and a `#anchor` matches a heading of the target (GitHub's slug rules: accents kept, `-1` for repeats, fenced `#` lines are not headings). |
| `parity` | `<name>.md` and `<name>.pt-BR.md` have the same sequence of heading levels (headings are translated, so the text is not compared), and a `README.md` has a `README.pt-BR.md`. |
| `version`, `plugins` | A version written on the same line as a plugin's name matches that plugin's `plugin.json`, and the root READMEs link every plugin of the catalog. |

Configuration is `.doc-truth.json` at the repository root (an unknown key is an error):

```json
{
  "exclude": ["docs/plans/**", "**/CHANGELOG.md"],
  "ignore_paths": [".ar-board/", "decisions.json"],
  "allow": []
}
```

- `exclude`: documents that are not checked (historical, generated). They stay valid link targets.
- `ignore_paths`: paths that do not exist in the tree on purpose (created at run time, or written as shorthand). A pattern with no `/` matches a name in any folder; with a `/` inside it starts at the repository root; `**` crosses folders and `*` does not.
- `allow`: fingerprints of accepted findings. A fingerprint is a hash of the category, the document and the value, never the line, so an edit above an accepted finding does not bring it back.

It is a heuristic: a path in prose that is only an example will be reported, and `ignore_paths` or `allow` is how you say so.

## Safety

Every tool in this plugin leaves your tracked files alone, none of them uses the network, and none runs a command a document cites. They do trust the repository's own git configuration (git reads it), so do not run them on a repository you do not trust.

| Categoria | O que confere |
| --- | --- |
| `path` | Um caminho citado entre crases ou em bloco de código existe na **árvore do git** (não só no seu disco, para o resultado ser o mesmo no CI). Marcadores (`<nome>`, `PATH`), URLs, flags, caminhos absolutos, diagramas de árvore e escolhas como `A/R/M` não são caminhos. |
| `link`, `anchor` | Um link relativo aponta para algo que existe, e uma `#âncora` bate com um título do alvo (regras de slug do GitHub: acentos mantidos, `-1` para repetidos, linhas com `#` dentro de bloco de código não são títulos). |
| `parity` | `<name>.md` e `<name>.pt-BR.md` têm a mesma sequência de níveis de título (os títulos são traduzidos, então o texto não é comparado), e todo `README.md` tem um `README.pt-BR.md`. |
| `version`, `plugins` | Uma versão escrita na mesma linha do nome de um plugin bate com o `plugin.json` dele, e os READMEs da raiz linkam todos os plugins do catálogo. |

A configuração é o `.doc-truth.json` na raiz do repositório (chave desconhecida é erro):

```json
{
  "exclude": ["docs/plans/**", "**/CHANGELOG.md"],
  "ignore_paths": [".ar-board/", "decisions.json"],
  "allow": []
}
```

- `exclude`: documentos que não são conferidos (históricos, gerados). Continuam valendo como alvo de link.
- `ignore_paths`: caminhos que não existem na árvore de propósito (criados em execução, ou escritos como abreviação). Um padrão sem `/` vale para o nome em qualquer pasta; com `/` no meio, parte da raiz; `**` atravessa pastas e `*` não.
- `allow`: fingerprints de achados aceitos. O fingerprint é um hash da categoria, do documento e do valor, nunca da linha: uma edição acima de um achado aceito não o traz de volta.

É uma heurística: um caminho em texto corrido que é só um exemplo será reportado, e `ignore_paths` ou `allow` é como você diz isso.

#!/usr/bin/env python3
# handoff 0.2.0 - nota de fim de sessao com fatos do git coletados e citacoes conferidas (somente stdlib e git)
# SPDX-License-Identifier: MIT
# Copyright (c) 2026 Diogo Winck
#
# Uso:
#   handoff.py collect [REPO] [--base REF] [--json]                   # fatos do git (branch, ponta, a frente/atras, sujos...)
#   handoff.py write   [REPO] --draft FILE|- [--out DIR] [--base REF] # confere as citacoes e grava .handoff/AAAA-MM-DD-hhmmss.md
#   handoff.py verify  FILE [REPO] [--json]                           # confere as citacoes de uma nota ou rascunho
#   handoff.py resume  [REPO] [--file FILE] [--json]                  # mostra a nota mais recente e o que mudou desde entao
# Saida: 0 tudo conferido, 1 citacao nao verificada ou algo mudou, 2 erro.
import argparse
import json
import os
import re
import subprocess
import sys
import time
from pathlib import Path

VERSION = "0.2.0"
SCHEMA = 1  # of the --json output and of the data block inside a note
NOTE_DIR = ".handoff"
RECENT = 5  # commits listed in the note

# git never prompts, never runs the repository's hooks or a filesystem monitor, and never uses the network
GIT_FLAGS = ["-c", "core.quotepath=off", "-c", "core.fsmonitor=false", "-c", "core.hooksPath=" + os.devnull,
             "-c", "protocol.allow=never", "-c", "log.showSignature=false", "-c", "i18n.logOutputEncoding=UTF-8"]


class HandoffError(Exception):
    """Something the person must fix before the tool can run (exit code 2)."""


def git(root, *args):
    env = dict(os.environ, GIT_TERMINAL_PROMPT="0")
    r = subprocess.run(["git", *GIT_FLAGS, "-C", str(root), *args], capture_output=True, env=env)
    return r.returncode, r.stdout.decode("utf-8", "replace")


def repo_root(path):
    rc, out = git(path, "rev-parse", "--show-toplevel")
    if rc != 0:
        raise HandoffError(f"{path} nao e um repositorio git")
    return Path(out.strip())


def resolve(root, ref):
    """The commit a ref names, or None. Full ref names are used where it matters so a tag cannot shadow a branch."""
    rc, out = git(root, "rev-parse", "--verify", "--quiet", ref + "^{commit}")
    return out.strip() if rc == 0 and out.strip() else None


def detect_base(root, override=None):
    """--base, else the branch origin/HEAD points to, else the first of base, main, master."""
    if override:
        if resolve(root, override) is None:
            raise HandoffError(f"a base '{override}' nao existe")
        return override
    rc, out = git(root, "symbolic-ref", "--quiet", "--short", "refs/remotes/origin/HEAD")
    if rc == 0 and "/" in out.strip():
        short = out.strip().split("/", 1)[1]
        if resolve(root, "refs/heads/" + short):
            return short
    for name in ("base", "main", "master"):
        if resolve(root, "refs/heads/" + name):
            return name
    return None


def base_ref(root, base):
    """The full ref to compare with: the local branch when there is one."""
    local = "refs/heads/" + base
    return local if resolve(root, local) else base


def worktrees(root):
    rc, out = git(root, "worktree", "list", "--porcelain")
    items, cur = [], {}
    for line in out.splitlines() + [""]:
        if not line:
            if cur.get("path"):
                items.append(cur)
            cur = {}
        elif line.startswith("worktree "):
            cur["path"] = line[len("worktree "):]
        elif line.startswith("branch "):
            cur["branch"] = line[len("branch refs/heads/"):] if line.startswith("branch refs/heads/") else line[len("branch "):]
    return items


def collect(root, base=None):
    """The git facts a handoff note is built on: all of them come from git, none from memory."""
    rc, head = git(root, "symbolic-ref", "--quiet", "--short", "HEAD")
    branch = head.strip() if rc == 0 else None
    tip = resolve(root, "HEAD")
    rc, up = git(root, "rev-parse", "--abbrev-ref", "--symbolic-full-name", "@{upstream}")
    upstream = up.strip() if rc == 0 and up.strip() else None
    base_name = detect_base(root, base)
    ahead = behind = None
    if base_name and tip:
        rc, counts = git(root, "rev-list", "--left-right", "--count", f"{base_ref(root, base_name)}...HEAD")
        if rc == 0 and len(counts.split()) == 2:
            behind, ahead = (int(n) for n in counts.split())
    rc, status = git(root, "status", "--porcelain=v1", "-z", "--untracked-files=all")
    modified, untracked = [], []
    entries = status.split("\0")
    i = 0
    while i < len(entries):
        entry = entries[i]
        i += 1
        if len(entry) < 4:
            continue
        code, path = entry[:2], entry[3:]
        if code[0] in "RC":  # renames carry the old name as a second field
            i += 1
        if path.startswith(NOTE_DIR + "/"):  # the notes are not work in progress; otherwise writing one would change the git state
            continue
        (untracked if code == "??" else modified).append(path)
    rc, stashes = git(root, "stash", "list")
    rc, log = git(root, "log", f"-{RECENT}", "--format=%h%x00%s") if tip else (1, "")
    commits = [dict(zip(("sha", "subject"), line.split("\0", 1))) for line in log.splitlines() if "\0" in line]
    return {"schema": SCHEMA, "branch": branch, "tip": tip, "upstream": upstream, "base": base_name,
            "ahead": ahead, "behind": behind, "modified": sorted(modified), "untracked": sorted(untracked),
            "stashes": len([l for l in stashes.splitlines() if l]),
            "worktrees": [{"path": w["path"], "branch": w.get("branch")} for w in worktrees(root)],
            "commits": commits}


CITATION = re.compile(r"`(commit|branch|file):([^`\s]+)`")
HEX_ID = re.compile(r"[0-9a-fA-F]{7,40}")
LINE_SUFFIX = re.compile(r":\d+(?::\d+)?$")
UNVERIFIED = " [nao verificado]"


def find_citations(text):
    """Every typed citation in a note: `commit:abc1234`, `branch:feat/x`, `file:path/to/f.py:42`. An untyped
    backtick span is prose and is never checked. Returns (kind, value, start, end) per citation."""
    return [(m.group(1), m.group(2), m.start(), m.end()) for m in CITATION.finditer(text)]


def check_citation(root, kind, value):
    """(verified, sha, why): `sha` is what the citation pointed at (commits and branches), `why` explains a failure."""
    if kind == "commit":
        if not HEX_ID.fullmatch(value):
            return False, None, "id de commit invalido (7 a 40 caracteres hexadecimais)"
        sha = resolve(root, value)
        return (True, sha, "") if sha else (False, None, "o commit nao existe")
    if kind == "branch":
        for ref in ("refs/heads/" + value, "refs/remotes/" + value):
            sha = resolve(root, ref)
            if sha:
                return True, sha, ""
        return False, None, "a branch nao existe (local ou remota)"
    path = LINE_SUFFIX.sub("", value)
    parts = path.split("/")
    if path.startswith("/") or ".." in parts or not path:
        return False, None, "o caminho deve ser relativo a raiz do repositorio"
    target = Path(root) / path
    try:  # a symlink that leads outside the repository is not a file of the repository
        inside = target.resolve().is_relative_to(Path(root).resolve())
    except (OSError, RuntimeError):
        inside = False
    if not inside:
        return False, None, "o caminho sai do repositorio"
    return ((True, None, "") if target.exists() else (False, None, "o arquivo nao existe na arvore de trabalho"))


def check_text(root, text):
    """One result per citation, in order."""
    out = []
    for kind, value, start, end in find_citations(text):
        ok, sha, why = check_citation(root, kind, value)
        line = text.count("\n", 0, start) + 1
        out.append({"type": kind, "value": value, "verified": ok, "sha": sha, "why": why, "line": line, "start": start, "end": end})
    return out


def mark_unverified(text, results):
    """Append ` [nao verificado]` after each citation that failed, once: a note is never marked twice and no
    text is ever removed."""
    out, last = [], 0
    for r in results:
        out.append(text[last:r["end"]])
        last = r["end"]
        if not r["verified"] and not text.startswith(UNVERIFIED, r["end"]):
            out.append(UNVERIFIED)
    out.append(text[last:])
    return "".join(out)

    """The machine-readable part of a note, as one HTML comment. `--` is escaped so no text inside it can end
    the comment early."""
    text = json.dumps(data, ensure_ascii=True, separators=(",", ":")).replace("--", "-\\u002d")
    return f"<!-- handoff:data {text} -->"


FACT_TYPES = {"branch": (str, type(None)), "tip": (str, type(None)), "upstream": (str, type(None)), "base": (str, type(None)),
              "ahead": (int, type(None)), "behind": (int, type(None)), "stashes": (int,)}


def valid_facts(facts):
    """A note is plain text anyone can edit or plant: its data block is used only if it has exactly the shape
    `collect` writes."""
    if not isinstance(facts, dict):
        return False
    for key, types in FACT_TYPES.items():
        if key not in facts or not isinstance(facts[key], types) or isinstance(facts[key], bool):
            return False
    return all(isinstance(facts.get(k), list) and all(isinstance(x, str) for x in facts[k]) for k in ("modified", "untracked"))


def parse_data(text):
    found = DATA_BLOCK.findall(text)
    if not found:
        return None
    try:
        data = json.loads(found[-1])
    except ValueError:
        return None
    return data if isinstance(data, dict) and valid_facts(data.get("facts")) else None


def notes_folder(root):
    """The default notes folder. A symlink there (a hostile repository can track one) would send the notes, or
    the reading of them, somewhere else, so it is refused."""
    folder = Path(root) / NOTE_DIR
    if folder.is_symlink():
        raise HandoffError(f"{folder} e um link simbolico: recuso escrever ou ler por ele (use --out para escolher a pasta)")
    return folder


def names(items):
    shown = ", ".join(items[:SHOWN])
    return shown + (f" e mais {len(items) - SHOWN}" if len(items) > SHOWN else "")


def git_section(facts):
    """The facts, as prose with no backtick spans (those are reserved for typed citations)."""
    branch = facts["branch"] or "(HEAD solta)"
    tip = f", ponta {facts['tip'][:7]}" if facts["tip"] else ", sem commits"
    lines = ["## Estado do git", "", f"- Branch: {branch}{tip}"]
    if facts["upstream"]:
        lines.append(f"- Upstream: {facts['upstream']}")
    if facts["base"] and facts["ahead"] is not None:
        lines.append(f"- Em relacao a base {facts['base']}: {facts['ahead']} a frente, {facts['behind']} atras")
    else:
        lines.append("- Base: nao encontrada")
    lines.append(f"- Arquivos modificados: {len(facts['modified'])}" + (f" ({names(facts['modified'])})" if facts["modified"] else ""))
    lines.append(f"- Arquivos novos (nao rastreados): {len(facts['untracked'])}" + (f" ({names(facts['untracked'])})" if facts["untracked"] else ""))
    lines.append(f"- Stashes: {facts['stashes']}")
    others = [w for w in facts["worktrees"][1:]]
    if others:
        lines.append("- Outros worktrees: " + ", ".join(f"{w['path']} ({w['branch'] or 'HEAD solta'})" for w in others))
    if facts["commits"]:
        lines += ["- Commits recentes:"] + [f"  - {c['sha']} {c['subject']}" for c in facts["commits"]]
    return "\n".join(lines)


def missing_sections(draft):
    return [name for name in SECTIONS if not re.search(rf"^#{{1,6}}[ \t]+{re.escape(name)}[ \t]*$", draft, re.M | re.I)]


def render_note(facts, draft, results, when):
    cites = [{"type": r["type"], "value": r["value"], "sha": r["sha"], "verified": r["verified"]} for r in results]
    data = {"schema": SCHEMA, "facts": facts, "citations": cites}
    return (f"# Handoff - {when} - {facts['branch'] or 'HEAD solta'}\n\n" + git_section(facts) + "\n\n"
            + draft.strip("\n") + "\n\n" + data_block(data) + "\n")


def write_note(root, draft, out_dir=None, base=None):
    """Check the draft's citations, mark the ones that fail, and save the note in a new file (never over another)."""
    facts = collect(root, base)
    results = check_text(root, draft)
    text = render_note(facts, mark_unverified(draft, results), results, time.strftime("%Y-%m-%d %H:%M", NOW()))
    folder = Path(out_dir) if out_dir else notes_folder(root)
    folder.mkdir(parents=True, exist_ok=True)
    stamp = time.strftime("%Y-%m-%d-%H%M%S", NOW())
    name, n = stamp + ".md", 2
    while True:
        try:  # private (the note may name internal paths) and exclusive (two runs in a second never share a file)
            fd = os.open(str(folder / name), os.O_WRONLY | os.O_CREAT | os.O_EXCL, 0o600)
            break
        except FileExistsError:
            name, n = f"{stamp}-{n}.md", n + 1
    with os.fdopen(fd, "w", encoding="utf-8") as fh:
        fh.write(text)
    return {"path": str(folder / name), "facts": facts, "citations": results, "missing": missing_sections(draft)}


def note_key(name):
    m = NOTE_NAME.fullmatch(name)
    return (m.group(1), int(m.group(2) or 1)) if m else None


def newest_note(folder):
    """The newest note of a folder: by its timestamp, then by its collision number. Anything that is not a regular
    note file is ignored."""
    best = None
    for p in Path(folder).glob("*.md"):
        key = note_key(p.name)
        if key and p.is_file() and not p.is_symlink() and (best is None or key > best[0]):
            best = (key, p)
    return best[1] if best else None


def drift(root, then, now):
    """What changed between the facts a note recorded and the repository now, as a list of messages."""
    out = []
    if then["branch"] != now["branch"]:
        out.append(f"a branch era {then['branch'] or '(HEAD solta)'} e agora e {now['branch'] or '(HEAD solta)'}")
    elif then["tip"] != now["tip"]:
        extra = ""
        if then["tip"] and resolve(root, then["tip"]):
            rc, count = git(root, "rev-list", "--count", f"{then['tip']}..HEAD")
            extra = f" ({count.strip()} commits novos)" if rc == 0 else ""
        else:
            extra = " (o commit antigo nao existe mais)"
        out.append(f"a ponta de {now['branch'] or 'HEAD'} mudou: {(then['tip'] or '-')[:7]} -> {(now['tip'] or '-')[:7]}{extra}")
    if (then["ahead"], then["behind"]) != (now["ahead"], now["behind"]):
        out.append(f"a frente/atras da base mudou: {then['ahead']}/{then['behind']} -> {now['ahead']}/{now['behind']}")
    before, after = set(then["modified"] + then["untracked"]), set(now["modified"] + now["untracked"])
    if before - after:
        out.append("arquivos sujos que ja nao estao: " + names(sorted(before - after)))
    if after - before:
        out.append("arquivos sujos novos: " + names(sorted(after - before)))
    if then["stashes"] != now["stashes"]:
        out.append(f"stashes: {then['stashes']} -> {now['stashes']}")
    return out


def resume(root, file=None):
    """The newest note, every citation checked again, and what drifted since it was written."""
    path = Path(file) if file else newest_note(notes_folder(root))
    if path is None:
        raise HandoffError(f"nao ha nota em {NOTE_DIR}/ (rode `write` primeiro)")
    if path.is_symlink() or not path.is_file():
        raise HandoffError(f"{path} nao e um arquivo de nota")
    text = path.read_text(encoding="utf-8", errors="replace")
    data = parse_data(text)
    results = check_text(root, text)
    recorded = {(c["type"], c["value"]): c.get("sha") for c in (data or {}).get("citations", [])}
    for r in results:
        before = recorded.get((r["type"], r["value"]))
        r["moved"] = bool(r["verified"] and before and r["sha"] and before != r["sha"])
    changes = None
    if data:
        try:
            now = collect(root, data["facts"].get("base"))
        except HandoffError:  # the recorded base is gone (or is not a ref at all): detect it again
            now = collect(root)
        changes = drift(root, data["facts"], now)
    return {"path": str(path), "text": text, "has_data": data is not None, "citations": results, "drift": changes}

# handoff (nota de fim de sessão com fatos conferidos)

Escreve uma nota para uma sessão nova, sem a sua memória, continuar o trabalho. Dois cuidados a distinguem de uma nota escrita de cabeça: os **fatos do git** (branch, ponta, commits a frente da base, arquivos modificados, stashes, worktrees) vêm do git, não de você; e toda **citação** que você escreve (commit, branch, arquivo) é conferida antes de a nota ser gravada, e a que não existe fica marcada `[nao verificado]`, sem apagar nada. Requer `python3` (stdlib) e `git`; não usa a rede.

## Quando usar

Quando o usuário pedir uma nota de passagem ou para retomar uma. Não se ofereça sozinho. Retomar só acontece sob pedido: nenhum hook, nenhuma oferta automática.

## Fluxo

### 0. Localizar o script

O script acompanha esta skill: `${CLAUDE_SKILL_DIR}/scripts/handoff.py`. Use-o direto, sempre com `python3 -I`.

```bash
test -f "${CLAUDE_SKILL_DIR}/scripts/handoff.py" && echo OK || echo FALTA
```

Se `${CLAUDE_SKILL_DIR}` aparecer sem ser substituído, use no lugar dele o caminho mostrado como "Base directory for this skill" quando a skill foi carregada, escrito por extenso em cada comando.

### 1. Escrever o rascunho

Escreva o rascunho com **estes quatro títulos**, nesta ordem, sem acentos (a ferramenta avisa se faltar algum, e nunca inventa o conteúdo):

```markdown
## O que foi feito
## Decisoes e por que
## Proximos passos
## O que falhou ou travou
```

O estado do git não entra no rascunho: a ferramenta o acrescenta no topo da nota. Em cada seção seja concreto: o que mudou, o que foi decidido e descartado (com o motivo, para ninguém refazer a discussão), a primeira coisa a fazer ao retomar, e as tentativas que não deram certo.

**Cite com tipo.** Só estas formas, entre crases, são conferidas; uma crase sem tipo é texto:

- `` `commit:abc1234` ``: um commit (7 a 40 caracteres hexadecimais);
- `` `branch:nome` ``: uma branch local ou remota (`origin/main`);
- `` `file:caminho/do/arquivo.py:42` ``: um arquivo relativo à raiz do repositório, com a linha opcional.

Cite só o que você viu existir nesta sessão. Se a nota não tiver nenhuma citação tipada, nada é conferido: diga isso ao usuário.

### 2. Gravar

```bash
python3 -I "${CLAUDE_SKILL_DIR}/scripts/handoff.py" write <repositório> --draft - <<'EOF'
## O que foi feito
...
EOF
```

A nota vai para `.handoff/AAAA-MM-DD-hhmmss.md` (privada, uma por execução, nunca sobrescreve outra). Código de saída: `0` tudo conferido, `1` alguma citação não verificada (a nota foi gravada com a marca), `2` erro. Leia o relatório: se houver citações não verificadas, diga quais e **proponha corrigir** (um novo `write` cria outra nota); se houver "aviso: falta a secao", diga qual.

`collect` mostra só os fatos do git; `verify <arquivo>` confere as citações de qualquer nota ou rascunho sem alterar o arquivo.

### 3. Retomar (só sob pedido)

```bash
python3 -I "${CLAUDE_SKILL_DIR}/scripts/handoff.py" resume <repositório>
```

Mostra a nota mais recente (`--file` escolhe outra), confere de novo cada citação e lista o que mudou desde que ela foi escrita: a ponta de uma branch que andou, a contagem a frente/atrás da base, arquivos modificados que sumiram ou apareceram, stashes. Saída `0` sem nada novo, `1` com mudança ou citação com problema. **Apresente as diferenças antes de agir** e não retome o plano da nota às cegas: o repositório pode ter andado.

## Regras

- `.handoff/` não deve ir para o git: as notas podem citar caminhos internos ou texto colado. A ferramenta não edita `.gitignore`; sugira a linha `.handoff/` e só a acrescente com o OK do usuário. Não publique nem commite uma nota.
- Não escreva na nota algo que você não verificou como se fosse fato: o que não for certo, diga que é suposição.
- Somente leitura no repositório: a ferramenta só escreve a nota, e recusa uma pasta `.handoff` que seja link simbólico. Não rode em um repositório em que você não confia: o git lê a configuração local dele. Se `git` não existir no PATH, diga isso ao usuário.

class MarkerTest(unittest.TestCase):
    def test_a_comment_that_starts_with_the_marker(self):
        text = "# TODO: shell\n// FIXME handle it\n-- TODO sql\n/* TODO block */\n * TODO inside a block\n; TODO ini\n#TODO tight\n"
        self.assertEqual(found(text), [

        text = "x = 1  # TODO: later\nfoo();  // FIXME(alice): broken\n"
        self.assertEqual(found(text), [(1, "TODO", "later"), (2, "FIXME", "(alice): broken")])

        for line in ["# TODOS later", "# todo: lower", "# Todo: mixed", "# XXX", "# HACK", "We should TODO this",

# SPDX-License-Identifier: MIT

# Uso:
#   todo_sweep.py scan   [REPO] [--limit N] [--max-blame N] [--out DIR]   # acha os TODO/FIXME, mede a idade, escreve batch.json + scan.json
#   todo_sweep.py check  DIR                                              # valida batch.json + scan.json
#   todo_sweep.py report DIR                                              # grava report.md e report.json a partir das decisoes
# O painel e o capy_board.py desta skill (`serve DIR`). Nenhum arquivo-fonte e editado.
import argparse
import hashlib
import json
import os
import re
import subprocess
import sys
import time
from pathlib import Path

VERSION = "0.3.0"
SCHEMA = 1
WORK_DIR = ".todo-sweep"
LEDGER = "ledger.json"
MAX_FILE = 1024 * 1024  # bytes; larger files are skipped
TEXT_MAX = 200
CONTEXT = 2  # lines shown before and after a TODO
LEAD = re.compile(r"^\s*(?:#+|//+|--|/\*+|\*+|;+)\s*(TODO|FIXME)\b(.*)$")  # a comment line that starts with the marker
TRAIL = re.compile(r"\S.*?\s(?:#+|//+)\s*(TODO|FIXME)\b(.*)$")  # a trailing comment after code
SKIP_SUFFIXES = (".md", ".markdown")  # prose mentions TODO; it is not a code comment
ZERO_SHA = "0" * 40
NOW = time.time  # a function: the tests replace it
LABELS = {"approve": {"text": "Resolver", "tone": "safe"}, "reject": {"text": "Descartar", "tone": "danger"},
          "maybe": {"text": "Manter", "tone": "caution"}}

# git never prompts, never runs the repository's hooks or a filesystem monitor, and never uses the network
GIT_FLAGS = ["-c", "core.quotepath=off", "-c", "core.fsmonitor=false", "-c", "core.hooksPath=" + os.devnull,
             "-c", "protocol.allow=never", "-c", "log.showSignature=false"]


class SweepError(Exception):
    """Something the person must fix before the tool can run (exit code 2)."""


def git(root, *args):
    env = dict(os.environ, GIT_TERMINAL_PROMPT="0")
    r = subprocess.run(["git", *GIT_FLAGS, "-C", str(root), *args], capture_output=True, env=env)
    return r.returncode, r.stdout.decode("utf-8", "replace")


def repo_root(path):
    rc, out = git(path, "rev-parse", "--show-toplevel")
    if rc != 0:
        raise SweepError(f"{path} nao e um repositorio git")
    return Path(out.strip())


def write_private(path, text):
    """Atomic and private (mode 0600): the cards quote code, and a ledger must never be half written."""
    path = Path(path)
    tmp = path.with_name(path.name + ".tmp")
    fd = os.open(str(tmp), os.O_WRONLY | os.O_CREAT | os.O_TRUNC, 0o600)
    with os.fdopen(fd, "w", encoding="utf-8") as fh:
        fh.write(text)
    os.replace(tmp, path)


def dump_json(obj):
    return json.dumps(obj, indent=2, ensure_ascii=False) + "\n"


# ---------------------------------------------------------------- finding the markers

def find_todos(text):
    """Every TODO or FIXME inside a comment: (line number, marker, text, context). Upper case, whole word; the
    comment must start the line or trail some code. It is a heuristic (a `# TODO` inside a string after a space
    matches) and the README says so."""
    lines = text.splitlines()
    out = []
    for i, line in enumerate(lines):
        m = LEAD.match(line) or TRAIL.match(line)
        if not m:
            continue
        body = re.sub(r"\s*\*/\s*$", "", re.sub(r"^[:\s]+", "", m.group(2))).strip()[:TEXT_MAX]
        lo, hi = max(0, i - CONTEXT), min(len(lines), i + CONTEXT + 1)
        out.append((i + 1, m.group(1), body, [(n + 1, lines[n][:160]) for n in range(lo, hi)]))
    return out


def read_source(root, rel):
    """A tracked text file's content, or None: symlinks, folders, binary files and files over 1 MB are skipped."""
    path = Path(root) / rel
    try:
        if path.is_symlink() or not path.is_file() or path.stat().st_size > MAX_FILE:
            return None
        data = path.read_bytes()
    except OSError:
        return None
    if b"\0" in data[:8192]:
        return None
    return data.decode("utf-8", errors="replace")


def todo_id(file, text, n):
    """Who a TODO is, never by its line: its file, its text and which of identical ones it is."""
    return hashlib.sha256(f"{file}|{text}|{n}".encode("utf-8")).hexdigest()[:16]


def scan_files(root):
    """Every hit in the tracked files, in the order the files are listed, with no age yet."""
    rc, out = git(root, "ls-files", "-z")
    if rc != 0:
        raise SweepError(f"{root} nao e um repositorio git")
    hits = []
    for rel in sorted(p for p in out.split("\0") if p):
        if rel.lower().endswith(SKIP_SUFFIXES):
            continue
        text = read_source(root, rel)
        if text is None:
            continue
        seen = {}
        for line, marker, body, context in find_todos(text):
            n = seen.get(body, 0)
            seen[body] = n + 1
            hits.append({"file": rel, "line": line, "marker": marker, "text": body, "context": context,
                         "todo_id": todo_id(rel, body, n), "age": None, "age_reason": "alem do limite de --max-blame"})
    return hits

HEADER = re.compile(r"^([0-9a-f]{40}) \d+ (\d+)(?: \d+)?$")


def parse_blame(out):
    """`git blame --porcelain` output as {final line: {sha, time, boundary}}. A commit's headers are printed only
    the first time it appears, so they are remembered by sha."""
    info, entries, cur = {}, {}, None
    for line in out.splitlines():
        m = HEADER.match(line)
        if m and (cur is None or cur.get("done")):
            cur = {"sha": m.group(1), "final": int(m.group(2)), "done": False}
            info.setdefault(cur["sha"], {})
        elif cur is not None and not cur["done"]:
            if line.startswith("\t"):
                data = info[cur["sha"]]
                entries[cur["final"]] = {"sha": cur["sha"], "time": data.get("author-time"), "boundary": "boundary" in data}
                cur["done"] = True
            else:
                key, _, value = line.partition(" ")
                info[cur["sha"]][key] = value
    return entries


def is_shallow(root):
    rc, out = git(root, "rev-parse", "--is-shallow-repository")
    return rc == 0 and out.strip() == "true"


def blame_ages(root, hits, cap):
    """Give an age to the first `cap` hits, in the order given: the days since the line's last change (author
    time). Uncommitted lines and a shallow clone's boundary commits have no age, and say why."""
    by_file = {}
    for h in hits[:cap]:
        by_file.setdefault(h["file"], []).append(h)
    now = NOW()
    shallow = is_shallow(root)  # blame calls the repository's root commit a boundary too, and its age is real
    for rel, group in by_file.items():
        args = ["blame", "--porcelain"]
        for h in group:
            args += ["-L", f"{h['line']},{h['line']}"]
        rc, out = git(root, *args, "--", rel)
        entries = parse_blame(out) if rc == 0 else {}
        for h in group:
            e = entries.get(h["line"])
            if e is None:
                h["age_reason"] = "sem historico (arquivo novo ou o blame falhou)"
            elif e["sha"] == ZERO_SHA or e["time"] is None:
                h["age_reason"] = "linha nao commitada"
            elif e["boundary"] and shallow:
                h["age_reason"] = "limite de um clone raso (o historico anterior nao esta aqui)"
            else:
                t = int(e["time"])
                h["age"] = {"days": max(0, int((now - t) // 86400)), "time": t, "commit": e["sha"][:7]}
                h["age_reason"] = ""
    return hits

def area(file):

def order_hits(hits):
    """Oldest first; what has no age comes after, in the order the files are listed."""
    aged = sorted((h for h in hits if h["age"]), key=lambda h: (-h["age"]["days"], h["file"], h["line"]))
    return aged + [h for h in hits if not h["age"]]


def age_text(h):

    return groups

# todo-sweep (triagem de TODO e FIXME)

Procura `TODO` e `FIXME` dentro de comentários dos arquivos rastreados pelo git, mede a idade de cada um com `git blame` e os mostra, **do mais antigo ao mais novo**, como cards num painel local: o usuário marca **Resolver** (`A`), **Descartar** (`R`) ou **Manter** (`M`), e o resultado é um **relatório somente leitura**. A ferramenta nunca edita um arquivo-fonte. Requer `python3` (stdlib) e `git`; não usa a rede.

Descartar e Manter ficam registrados em `.todo-sweep/ledger.json`: o próximo scan oferece os próximos TODOs, não os mesmos. Resolver não é registrado: o TODO continua sendo oferecido até sumir do código.

## Quando usar

Quando o usuário pedir a triagem de TODOs ou FIXMEs. Não se ofereça sozinho. Cada lote tem no máximo 20 cards (`--limit`); com centenas de TODOs são várias rodadas.

## Fluxo

### 0. Localizar os scripts

Os scripts acompanham esta skill: `${CLAUDE_SKILL_DIR}/scripts/todo_sweep.py` (a ferramenta) e `${CLAUDE_SKILL_DIR}/scripts/capy_board.py` (o painel). Use-os direto, sempre com `python3 -I`.

```

### 1. Varrer

```bash

```

Opções: `--limit N` (cards por lote, padrão 20), `--max-blame N` (quantos medir com `git blame`, padrão 300) e `--out <pasta>`. O lote vai para `.todo-sweep/todo-sweep-AAAA-MM-DD/` (`batch.json` e `scan.json`, privados). Leia o resumo e **repasse os avisos**: quantos TODOs foram achados e quantos já decididos; quantos ficaram **sem idade** (linha não commitada, limite de um clone raso, ou além do `--max-blame`). A idade é a de **quando a linha mudou pela última vez**, não de quando o TODO nasceu: um reformat zera a idade.

O painel avança sozinho depois de decidir. O painel só escuta em `127.0.0.1`; nunca exponha a porta nem o token.

Os de **Manter** ficam como estão. Para outro lote, rode o `scan` de novo.

- **Noise rules for paths (R5).** A token is also not a path when it is a MIME type (`text/html`), a bare extension (`.svg`) or a choice written with single letters (`A/R/M`); a `NAME=value` assignment exposes its value; in code fences a line that starts with `#` or `/` (a comment, a Claude Code command), whatever follows ` #`, and tree diagrams are skipped. The first run on this repository found 594 findings; with these rules and the repository's `.doc-truth.json` it finds none.
- **Globs (R9).** A pattern with a trailing `/` also matches the folder itself, so a document may cite `.ar-board/`; a pattern with no other `/` matches a name in any folder.
- **Symlinks are never followed.** doc-truth reads only regular tracked files (a symlinked document or manifest is skipped), handoff refuses a `.handoff` folder that is a symlink and counts a `file:` citation that leaves the repository as unverified, todo-sweep refuses a `.todo-sweep` symlink and skips symlinked sources. An automatic security review of the first commits asked for this.
- **A note is untrusted text (R11-R13).** `resume` uses a note's data block only when it has exactly the shape `collect` writes, and detects the base again when the recorded one is gone or is not a ref.
- **`collect` leaves `.handoff/` out of the facts**, otherwise writing a note would change the state it records and `resume` would always report drift.
- **Blame boundary (R16).** `git blame` calls a repository's root commit a boundary too, and its age is real: only a shallow clone's boundary has no age.
- **TODO identity (R17).** The id also carries which of several identical texts in a file it is (`sha256(file|text|n)`), so empty or repeated TODOs stay distinct.
- **Real drift fixed (R10).** The Portuguese README of the repository and the one of ar-board had fewer sections than the English ones and were completed; paths written as shorthand relative to a plugin (about thirty) and the names of files the tools write at run time are in `ignore_paths`.
- **No CI change was needed**: `ci.yml` already loops over `plugins/*`.
