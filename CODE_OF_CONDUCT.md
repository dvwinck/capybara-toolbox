# Code of Conduct

We want this project to be a welcoming, harassment-free space for everyone, regardless of experience, background or identity.

**Expected:** be respectful and constructive; assume good faith; give and accept feedback graciously; focus on what is best for the project and its users.

**Not acceptable:** harassment, personal attacks, discriminatory language or jokes, publishing someone's private information, and sustained disruption of discussions.

Maintainers may remove comments, issues or contributions that violate this code, and may restrict participation for repeated or serious violations. To report a problem, use GitHub's *Report content* feature or contact the maintainer listed in `.claude-plugin/marketplace.json`.

This Code of Conduct applies in all project spaces (issues, pull requests, discussions) and when someone represents the project in public.
